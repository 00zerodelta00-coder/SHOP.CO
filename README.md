## Ключевой функционал

* **Главная страница (`index.html`)** — главный баннер со статистикой, лента брендов, подборки товаров *New Arrivals* и *Top Selling*, выбор одежды по стилю (*Casual, Formal, Party, Gym*) и карусель отзывов.

* **Каталог товаров (`Category.html`)** — загрузка товаров с сервера с пагинацией, фильтрами по категориям, цене, цветам, размерам и стилю, а также сортировкой и поиском по названию.

* **Карточка товара (`Product.html`)** — галерея миниатюр, выбор цвета и размера, счётчик количества, переключение вкладок (*Product Details*, *Rating & Reviews*, *FAQs*) и блок похожих товаров (*You Might Also Like*).

* **Корзина (`Cart.html`)** — добавление товаров, изменение количества, удаление позиций, расчёт суммы заказа, скидки `-20%` и стоимости доставки.

* **Авторизация (`login.html`, `register.html`)** — регистрация и вход в аккаунт, сохранение сессии пользователя, отображение профиля в шапке и скрытие верхней рекламной плашки.

* **Адаптивность и уведомления** — всплывающие уведомления о действиях пользователя, автоматическая подстановка заглушки при отсутствии фото, мобильное меню, шторка фильтров и горизонтальная прокрутка карточек.

## Гайд по работе с Backend (FastAPI / Swagger UI)

Проект работает с сервером на **FastAPI**, у которого есть встроенная панель тестирования **Swagger UI** (открывается по адресу `/docs`).

### Доступные запросы

| Метод | Адрес | Доступ | Описание | 
| ----- | ----- | ----- | ----- | 
| `POST` | `/auth/register` | Открытый | Регистрация нового пользователя и выдача `accessToken` | 
| `POST` | `/auth/login` | Открытый | Вход в аккаунт по email и паролю | 
| `GET` | `/auth/me` | По токену | Получение данных текущего пользователя | 
| `GET` | `/products` | Открытый | Список товаров (пагинация, фильтры, сортировка) | 
| `GET` | `/products/{product_id}` | Открытый | Детальная информация о товаре по ID | 
| `GET` | `/cart` | По токену | Получение содержимого корзины | 
| `POST` | `/cart/items` | По токену | Добавление товара в корзину | 
| `PATCH` | `/cart/items/{item_id}` | По токену | Изменение количества товара в корзине | 
| `DELETE` | `/cart/items/{item_id}` | По токену | Удаление одного товара из корзины | 
| `DELETE` | `/cart` | По токену | Полная очистка корзины | 

### Как проверить запросы через Swagger UI

1. **Создайте аккаунт:**

   * Откройте `/docs`, нажмите на **`POST /auth/register`** и выберите **`Try it out`**.

   * Введите данные нового пользователя и нажмите **`Execute`**:

     ```json
     {
       "name": "Demo User",
       "email": "demo@shop.co",
       "password": "password123"
     }
     ```

   * Скопируйте значение `accessToken` из ответа сервера ниже.

2. **Авторизуйтесь в Swagger:**

   * Нажмите кнопку **`Authorize`** в правом верхнем углу страницы `/docs`.

   * Вставьте скопированный `accessToken` в поле **Value** и нажмите **`Authorize`**, затем **`Close`**.

3. **Управляйте корзиной и профилем:**

   * Выполните **`GET /auth/me`**, чтобы проверить текущий аккаунт.

   * Используйте **`POST /cart/items`**, чтобы добавить товар в корзину на сервере — после обновления `Cart.html` на сайте он сразу появится в списке.

   * Для быстрой очистки всей корзины выполните **`DELETE /cart`**.

> **Примечание по аккаунтам:** на сервере нет функции удаления пользователя. Чтобы выйти из тестового аккаунта на сайте, нажмите кнопку **Logout** в шапке, после чего можно зарегистрировать новый аккаунт.
